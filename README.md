# Video game sales analysis with Power BI

## Overview

This project presents an interactive Power BI report for exploring historical video game sales. The analysis transforms sales records into clear visual insights, making it easier to compare market performance by title, platform, genre, publisher, region, and release period.

Rather than examining isolated records, the dashboard combines the main indicators within a structured analytical view. As a result, users can identify market leaders, regional differences, historical trends, and changes in consumer demand.

## Objectives

The project was developed to:

- Examine the evolution of video game sales over time.
- Identify the leading games, platforms, genres, and publishers.
- Compare sales performance across geographic markets.
- Reveal patterns that may not be evident in the original dataset.
- Provide an interactive report for business intelligence and exploratory analysis.

## Analysis scope

The report supports the exploration of:

- Global and regional sales.
- Sales trends by release year.
- Performance by video game title.
- Platform and console comparisons.
- Genre preferences.
- Publisher performance.
- Differences among the available regional markets.
- Rankings and filtered comparisons.

## Dashboard value

The dashboard converts historical sales data into an accessible resource for analysis and decision-making. Interactive filters allow users to move from a general market overview to more detailed comparisons. Meanwhile, visual rankings and trends help reveal which products and categories achieved the strongest commercial performance.

Although the project focuses on the video game industry, the analytical process demonstrates transferable business intelligence skills, including data preparation, KPI development, comparative analysis, visual storytelling, and report usability.

## Data preparation

Before visualization, the dataset was reviewed and prepared for analysis. The workflow may include:

1. Importing the source data into Power BI.
2. Reviewing data types and consistency.
3. Handling incomplete or invalid records.
4. Standardizing categorical and numerical fields.
5. Creating the relationships and calculations required by the report.
6. Validating the resulting indicators against the source data.

## How to use

1. Clone or download the repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Update the source path if Power BI requests access to the original dataset.
4. Refresh the report.
5. Use the available filters and visual elements to explore sales from different perspectives.

## Limitations

The findings reflect the scope, coverage, and update period of the source dataset. Therefore, they should be interpreted as a historical analysis rather than as a representation of the current video game market.
